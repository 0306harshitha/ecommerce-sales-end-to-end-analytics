# ecommerce-sales-end-to-end-analytics

This project demonstrates an end-to-end data analytics workflow on an Ecommerce Sales dataset.
The objective is to analyze sales performance, customer behavior, and revenue trends using Python, SQL, Excel, and Power BI.

**The project covers:**

Data Cleaning

Exploratory Data Analysis (EDA)

KPI Analysis

SQL Business Queries

Excel Dashboard

Interactive Power BI Dashboard

**🛠️ Tools & Technologies Used**

Python (Pandas, Matplotlib, Seaborn)

SQL

Microsoft Excel

Power BI

Git & GitHub

**The dataset contains:**

OrderID

OrderDate

CustomerID

Gender

Age

Product

Category

Quantity

Price

Region

Payment Method

**Additional column created:**

Revenue = Quantity × Price

**🧹 Step 1 – Data Cleaning (Python)**

Checked missing values using isnull()

Checked duplicates using duplicated()

Converted OrderDate to datetime format

Created Month and Year columns

Created Revenue column
**
📊 Step 2 – Exploratory Data Analysis (Python)**

Performed analysis on:

Monthly Revenue Trend

Category-wise Revenue

Region-wise Sales

Top Customers

Payment Method Distribution

Visualizations created using Matplotlib & Seaborn.

**🗃️ Step 3 – SQL Analysis**

Executed business queries such as:

Total Revenue

Total Orders

Revenue by Category

Revenue by Region

Monthly Sales Analysis

Top Customers by Revenue

**📈 Step 4 – Excel Dashboard**

Imported CSV data

Created Revenue column

Built Pivot Tables

Created KPI Metrics:

Total Revenue

Total Orders

Average Order Value

Designed dashboard layout

📊 **Step 5 – Power BI Dashboard**

Created interactive dashboard with:

KPI Cards

Sales Trend Line Chart

Category Revenue Bar Chart

Region-wise Sales

Slicers:

Category

Region

Payment Method

Date

Used DAX measures for KPI calculations.
